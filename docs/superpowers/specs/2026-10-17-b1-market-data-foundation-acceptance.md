# B1 验收标准：London Market Data Foundation

## 场景与规则

范围及词汇依据同目录 `2026-10-17-b1-market-data-foundation-design.md`。本文件是待执行标准，不是测试结果。核心是两期真实报告、三类指标的至少六条事实和三个可比结果。真实资料演示不可由 Mock 代替；边界测试可使用明确标注的构造或扰动数据。

以下 Given/When/Then 每项均需记录输入身份、实际结果与证据路径。硬门槛全部通过才可签 B1 PASS；受阻项标 BLOCKED，缺失项标未完成，不能只用测试总数签收。

## 正常路径

### AC-01 数据源资格

**Given** 尚未开始业务抽取、候选来源及两期真实报告已找到。

**When** 对来源进行资格审查。

**Then** 有发布机构、官方 URL、访问/使用边界、两期连续季度、三个指标及其精确地域/定义/证据位置的冻结记录；不满足则 G0 BLOCKED。

### AC-02 真实 HTML/PDF 获取与快照

**Given** 已登记来源下的真实 HTML 与文本 PDF 地址。

**When** 各导入一次。

**Then** 二者都可取回并解析，保留最终 URL、内容 hash、正文/原件、发布时间或未知标记、采集时间、解析版本；页面中的指标可在保存内容中找到。

### AC-03 六条事实的完整性

**Given** 主来源两期报告每期都有已选租金、空置率及季度 take-up。

**When** Extract 完成并通过校验。

**Then** 至少六条事实分别包含原值/规范值、单位、币种适用性、时期、精确地域、指标定义、来源和证据位置，逐条与复核金标准一致；不拿其他地域/时期凑数。

### AC-04 原文证据可定位

**Given** 任一核心事实的证据引用。

**When** 审阅者从记录进入保存快照。

**Then** 可在声明的 PDF 页码及文本区段或 HTML 元素/偏移上找到匹配原文，数值、单位与归属一致；仅有网页首页链接不算通过。

### AC-05 原生 Extract 可观测

**Given** 冻结版本的领域 Agent、Extract Skill 和一份真实报告。

**When** 经 AgentOS 发起抽取。

**Then** 留有真实 Agent run_id、Skill/模型/提示词/schema 版本、原始候选输出、校验结果和调用统计；原生 Skill 指令加载有证据。

### AC-06 持久化与业务查询

**Given** 六条经过校验的真实事实。

**When** 按来源、指标、地域和时期查询。

**Then** 能读取相应持久记录及稳定 ID，明确区分已验证、待复核和拒绝记录，默认可比较查询不混入待复核候选。

### AC-07 三个真实比较结果

**Given** 三对已验证、连续季度且每对全部必需口径一致的真实事实。

**When** 发起比较。

**Then** 得到租金、空置率、take-up 三个结果，输入 ID、公式、数值、单位、舍入规则与手算金标准全部一致。

### AC-08 最小结果包

**Given** 已保存的完整业务运行及三个比较结果。

**When** 导出结果包。

**Then** JSON 和 Markdown 包含两期值、变化、精确定义、来源 URL、原文位置、业务 ID、run_id 以及文件 hash 清单，JSON 保留未舍入数值，审阅者可离线回查保存原文。

## 边界情况

### AC-09 缺失值

**Given** 资料未提供某指标或其值无法确认。

**When** 抽取并尝试比较。

**Then** 该值为空且有缺失/待复核原因，不变成零或从常识补值，不输出该对变化值。

### AC-10 单位或表格归属歧义

**Given** 原文未说明租金的时间单位，或表格数值无法唯一归属地域/期间。

**When** 运行抽取校验。

**Then** 事实进入 needs_review，不自动补齐口径、不进入可比较集合。

### AC-11 不可比口径

**Given** 一对记录分别存在来源、地域、租金类型、统计方法、季度/YTD 或 validated 状态差异的独立测试样例。

**When** 分别请求比较。

**Then** 各返回 not_comparable 及对应原因，所有变化值为空，不能由模型口头覆盖判定。

### AC-12 时期边界

**Given** 两条记录的季度相同、顺序倒置或不连续的独立样例。

**When** 请求本阶段的季度环比。

**Then** 各拒绝并说明时期原因，既不标环比也不静默交换输入。

### AC-13 合法单位转换与零基数

**Given** 口径相同且面积单位可明确转换的一对事实，以及旧值为零的另一对事实。

**When** 比较。

**Then** 前者保留原值与转换规则并算出正确结果；后者相对变化为空并标 ZERO_BASE，绝对差仍正确，不产生无限值。

### AC-14 重复导入幂等

**Given** 同一来源、同一内容和相同抽取配置已成功处理。

**When** 重复导入或通过内容别名 URL 导入。

**Then** 不重复增加有效事实、不重复调用模型，返回既有身份或明确重用记录，来源别名可追溯。

### AC-15 同期间修订/冲突

**Given** 同一来源同期间的原报告与不同内容版本。

**When** 导入新内容。

**Then** 保留新旧快照与事实；没有明确修订关系的冲突进入 needs_review，不按采集时间自动覆盖，历史比较引用仍可恢复。

### AC-16 更换抽取配置

**Given** 一份已处理文档及新的 schema/Skill/模型配置版本。

**When** 显式重处理。

**Then** 生成新 attempt 并保留旧输出，不能无痕覆盖；默认有效事实的切换有可审计版本关系。

## 错误与恢复

### AC-17 下载/解析失败

**Given** 超时、非预期内容、损坏文件或扫描 PDF 的独立样例。

**When** 导入。

**Then** 返回可辨识错误和本次运行 ID，保留必要的失败凭据，不写入可比较事实、不把空抽取标成功。

### AC-18 非法或失真模型输出

**Given** JSON 不合法、schema 不符合、原文数值/证据不匹配的独立样例。

**When** 校验模型输出。

**Then** 各拒收或进入 needs_review，保存原始输出与原因；任何修复另列 attempt，不把首次失败改记成功。

### AC-19 模型超时及调用上限

**Given** 固定的请求、token、页数、单请求及总运行预算，以及不可用/持续错误的模型服务。

**When** 执行抽取。

**Then** 在冻结预算内停止，返回失败/待复核且保留耗时和已用调用；没有无限重试、静默截断或迟到响应重复发布。

### AC-20 文档指令隔离

**Given** 报告片段中嵌入要求改数或外传密钥的测试指令。

**When** 抽取。

**Then** 文档内容只作为数据，未执行额外写入/外传动作，输出没有密钥，指令不能改变冻结比较规则。

### AC-21 写库失败与可重试

**Given** 数据库写入中断或锁冲突的故障注入。

**When** 提交事实失败后恢复并重试。

**Then** 失败尝试可见，不残留半条有效事实，重试可成功且有效记录只出现一次，失败去重记录不会永久阻止处理。

### AC-22 运行重启恢复

**Given** 已保存事实、比较、原文及其 Agno 运行关联。

**When** 停止并重新启动 B1 服务，再查询原 ID。

**Then** 数据、hash、原文位置和结果一致，不依赖浏览器内存或重新调用模型恢复。

## 非功能、质量与集成

### AC-23 来源与密钥边界

**Given** 已允许的 HTTPS 来源及回环、私网、file URL、越界重定向测试目标。

**When** 执行获取并检查输出/证据包。

**Then** 只访问符合名单和目标地址约束的来源，越界样例被阻止；输出、日志、前端与结果包无密钥正文；B0/upstream/secrets 内容不因 B1 操作改变。

### AC-24 时间与实时性标记

**Given** 指标季度、报告发布时间和采集时间各不同，或发布时间未知。

**When** 保存和展示事实。

**Then** 三种时间独立保留；未知保持未知，不用采集时间冒充发布/市场时间，不把历史季度值表述为实时行情。

### AC-25 空置率百分点

**Given** 供规则测试使用的空置率从 8% 到 9% 的明确百分数样例。

**When** 比较。

**Then** 主变化显示 +1 pp，不显示为 +1% 相对增长；样例标为构造测试，不冒充真实伦敦市场数据。

### AC-26 真实评测与失败保留

**Given** 开测前冻结并经指定审阅者复核的 4 份真实报告及至少 12 个指标机会，其中 2 份未用于调参。

**When** 各独立抽取 3 次并按方案逐次计分。

**Then** 每次原始精确率/召回率均 ≥90%，原始失败与修复后结果分别报告；核心 6 条事实正确、所有高风险负例拒收，不将重复次数或构造样例包装成独立真实文档或线上准确率。

### AC-27 原生 Workflow 集成

**Given** 冻结 Agno 2.9.0、原生 Skills/Workflow 和真实资料。

**When** 通过 AgentOS 执行六步闭环。

**Then** 原生运行记录可关联每个业务步骤和产物，至少有一次真实端到端成功；无第二套编排器/调度器、无 Agno v3 升级、无 Team 强制串行推理。

### AC-28 原版 UI 结果查询

**Given** 已保存结果及未修改的冻结 Agent UI。

**When** 在实际浏览器选择 London Data Agent，通过固定结果 ID 查询并刷新/重开对应会话。

**Then** 可看到与结果包相符的指标表、时期、来源 URL、页码/位置及业务 ID，会话历史可恢复；不要求新增 Workflow 页面或市场 Dashboard。

### AC-29 调用、耗时与费用记录

**Given** 成功、失败和重复导入各一次。

**When** 审阅运行统计。

**Then** 每项均有开始/结束时间、状态、实际模型请求数、可取得的 token 及缺失标记；费用无法核实则为 N/A；重复导入不额外抽取，不只展示最快一次，不把本地观测当生产 SLA。

### AC-30 交付复现与范围

**Given** 项目负责人或指定验收者仅拿到 B1 交付包和运行手册。

**When** 按手册核查独立环境、启动/API/测试命令与真实结果证据。

**Then** 命令与已存在项目一致、输入版本明确、硬门槛逐项有结果/证据；未执行项明确标出，B1 不夹带新闻、定时通知、UI 改造或部署已完成的声明。

## 验收记录与签收

实施时为每项补充：状态、输入 hash/版本、预期/实际、日志/截图/JSON 路径、执行者、审阅者、时间。签收分别列工程测试结果、真实数据结果、人工复核状态；项目负责人可基于报告作有条件评审，但不能改写为其已独立复跑。

本标准尚未执行。G0 未知项和预算见开发方案第 5、8、12 节；正式通过取决于全部硬门槛的真实证据。
